# Flutter Lab Exam – Simple Codes (Sets 10 to 17)

🌐 **Live Web Page**: [https://fr8st7.github.io/flutterlabexam/](https://fr8st7.github.io/flutterlabexam/)

A clean, exam-ready collection of simple Flutter programs for Lab Exam Sets 10 to 17. Every program is kept strictly within 51 lines of code, formatted and tested for quick usage.

---

## ⚡ Quick Common Workflow

For any exam set:

```bash
flutter create project_name
cd project_name
code .
flutter run
# or for browser
flutter run -d chrome
```
